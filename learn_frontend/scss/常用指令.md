## @import 模块化导入指令详解

Sass 拓展了 `@import` 的功能，允许其导入 `SCSS` 或 `Sass` 文件。被导入的文件将合并编译到同一个 CSS 文件中，另外，被导入的文件中所包含的变量或者混合指令 (`mixin`) 都可以在导入的文件中使用。

### 传统 css 导入

通常，`@import` 寻找 `Sass` 文件并将其导入，但在以下情况下，`@import` 仅作为普通的 `CSS` 语句，不会导入任何 `Sass` 文件。传统的 `css` 导入：

```css
// 1. 文件拓展名是 .css；
@import 'public.css';
// 2. 文件名是url( )；
@import url(public);
// 3. 文件名以 http:// 开头；
@import 'http://xxx.com/xxx';
// 4. @import 包含 media queries。
@import 'landscae' screen and (orientation: landscape);
```

如果不在上述情况内，文件的拓展名是 `.scss` 或 `.sass`，则导入成功。没有指定拓展名，Sass 将会试着寻找文件名相同，拓展名为 `.scss` 或 `.sass` 的文件并将其导入。例如：

```scss
@import 'foo.scss';
// 或
@import 'foo';
```

### 基本使用

准备`public.scss`文件

```scss
$font-base-color: #333;
```

`index.sass`文件

```scss
@import 'public';
$color: #666;
.container {
  border-color: $color;
  color: $font-base-color;
}
```

编译后：

```css
.container {
  border-color: #666;
  color: #333;
}
```

### 导入多个文件

Sass 允许同时导入多个文件，例如同时导入 `rounded-corners` 与 `text-shadow` 两个文件：

```scss
@import 'rounded-corners', 'text-shadow';
```

### 使用 `#{ }` 插值语句

导入文件也可以使用 `#{ }` 插值语句，但不是通过变量动态导入 Sass 文件，只能作用于 CSS 的 `url()` 导入其方式为：

```scss
$family: unquote('Droid+Sans');
@import url('http://fonts.googleapis.com/css?family=\#{$family}');
```

编译后：

```css
@import url('http://fonts.googleapis.com/css?family=Droid+Sans');
```

### 局部文件(Partials)

`Sass`源文件中可以通过`@import`指令导入其他 Sass 源文件，被导入的文件就是局部文件，局部文件让 Sass 模块化编写更加容易。
如果一个目录正在被 Sass 程序监测，目录下的所有`scss/sass`源文件都会被编译，但通常不希望局部文件被编译，因为局部文件是用来被导入到其他文件的。
![局部文件(Partials)](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251008223851171.png)
如果不想局部文件被编译，文件名可以以下划线 `（_）`开头，这样就不会生成`public.css`和`public.css.map`文件了，比如下面：
`_theme.scss`文件

```scss
$border-color: #999;
$background-color: #f2f2f2;
```

`index.scss`文件

```scss
@import 'public';
@import 'theme';
$color: #666;
.container {
  border-color: $border-color;
  color: $font-base-color;
  background-color: $background-color;
}
```

编译后：

```css
.container {
  border-color: #999;
  color: #333;
  background-color: #f2f2f2;
}
```

::: tip 理解局部文件
就是说如果进行模块拆分，一些模块就可以作为局部文件，但是我们并不想去编译这些局部文件，只需要编译主文件（导入了局部文件的文件），这时候就可以使用这个方法了
:::
