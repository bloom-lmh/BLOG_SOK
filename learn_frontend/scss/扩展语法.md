## 语法嵌套规则

### 选择器嵌套

例如有这么一段 css
::: code-group

```css [正常 CSS 的写法]
.container {
  width: 1200px;
  margin: 0 auto;
}
.container .header {
  height: 90px;
  line-height: 90px;
}
.container .header .log {
  width: 100px;
  height: 60px;
}
.container .center {
  height: 600px;
  background-color: #f00;
}
.container .footer {
  font-size: 16px;
  text-align: center;
}
```

```scss [SCSS 的写法]
.container {
  width: 1200px;
  margin: 0 auto;
  .header {
    height: 90px;
    line-height: 90px;
    .log {
      width: 100px;
      height: 60px;
    }
  }
  .center {
    height: 600px;
    background-color: #f00;
  }
  .footer {
    font-size: 16px;
    text-align: center;
  }
}
```

:::

::: tip 总结
scss 选择器嵌套的优点在于避免了重复输入父选择器，复杂的 CSS 结构更易于管理
:::

### 父选择器&

在嵌套 CSS 规则时，有时也需要直接使用嵌套外层的父选择器，例如，当给某个元素设定 hover 样式时，或者当 body 元素有某个 classname 时，可以用 & 代表嵌套规则外层的父选择器。
比如用
::: code-group

```scss [sass 编写下面的代码]
.container {
  width: 1200px;
  margin: 0 auto;
  a {
    color: #333;
    &:hover {
      text-decoration: underline;
      color: #f00;
    }
  }
  .top {
    border: 1px #f2f2f2 solid;
    &-left {
      float: left;
      width: 200px;
    }
  }
}
```

```css [编译后的 CSS]
.container {
  width: 1200px;
  margin: 0 auto;
}
.container a {
  color: #333;
}
.container a:hover {
  text-decoration: underline;
  color: #f00;
}
.container .top {
  border: 1px #f2f2f2 solid;
}
.container .top-left {
  float: left;
  width: 200px;
}
```

:::
::: tip 总结
`&`其实就是父选择器的别名
:::

### 属性嵌套

有些 CSS 属性遵循相同的命名空间 (namespace)，比如 `font-family`, `font-size`, `font-weight` 都以 font 作为属性的命名空间。为了便于管理这样的属性，同时也为了避免了重复输入，Sass 允许将属性嵌套在命名空间中

:::code-group

```css [正常 CSS 的写法]
.container a {
  color: #333;
  font-size: 14px;
  font-family: sans-serif;
  font-weight: bold;
}
```

```scss [SCSS 的写法]
.container {
  a {
    color: #333;
    font: {
      size: 14px;
      family: sans-serif;
      weight: bold;
    }
  }
}
```

:::

::: warning 注意
注意 `font:` 后面要加一个空格
:::

## Scss 的两种注释方式

### 多行注释

::: code-group

```scss [一般使用]
// 标准的css多行注释 /* ... */ 会编译到.css文件中
/* 
    首页相关css
    version：#{$version}
 */
.container {
  .dot {
    /* 
      幻灯片指示点
      默认白色
      选中时蓝色
    */
    width: 10px;
    height: 10px;
    border-radius: 50%;
    background-color: #fff;
    &.active {
      background-color: blue;
    }
  }
}
```

```scss [! 符 ]
//将 ! 作为多行注释的第一个字符表示在压缩输出模式下保留这条注释并输出到 CSS 文件中，通常用于添加版权信息。
```

```scss [注释中使用变量值]
$version: '1.2.3';
/* This CSS is generated by My Snazzy Framework version #{$version}. */
// 编译为
/* This CSS is generated by My Snazzy Framework version 1.2.3. */
```

:::

### 单行注释

单行注释 `//` 不会编译到`.css`文件

```css
.swiper {
  // 网站幻灯片相关css
  width: 100%;
}
```
