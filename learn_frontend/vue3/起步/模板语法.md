# 模板语法

## 基本介绍

vue 使用了一种基于 HTML 的模板语法，允许我们声明式的将其组件实例的数据绑定到视图上。**在底层机制中，Vue 会将模板编译成高度优化的 JavaScript 代码，结合响应式系统，当应用状态变更时，Vue 能够智能地推导出需要重新渲染的组件的最少数量，并应用最少的 DOM 操作。**。

模板语法无非几个概念：

1. 文本插值
2. 属性绑定
3. 指令
4. 事件处理

## 文本插值

最基本的数据绑定形式是文本插值，它使用的是双大括号语法来声明：

```html
<span>Message: {{ msg }}</span>
```

渲染后，双大括号标签会被替换为相应组件实例中 msg 属性的值。同时每次 msg 属性更改时它也会同步更新。

## 插入 HTML

双大括号会将数据解释为纯文本，而不是 HTML。若想插入 HTML，你需要使用 v-html 指令，比如`rawHtml`是一段`html`代码`<span style="color: red">`：

```html
<p>Using text interpolation: {{ rawHtml }}</p>
<p>Using v-html directive: <span v-html="rawHtml"></span></p>
```

结果

```text
Using text interpolation: <span style="color: red">This should be red.</span>

Using v-html directive: This should be red.
```

这里看到的 `v-html` attribute 被称为一个指令。指令由 `v-` 作为前缀，表明它们是一些由 Vue 提供的特殊 attribute

## Attribute 绑定

### 一般语法

双大括号不能在 `HTML attributes` 中使用。想要响应式地绑定一个 attribute，应该使用 `v-bind` 指令：

```html
<div v-bind:id="dynamicId"></div>
```

`v-bind` 指令指示 Vue 将元素的 `id attribute` 与组件的 `dynamicId` 属性保持一致。如果绑定的值是 `null` 或者 `undefined`，那么该 attribute 将会从渲染的元素上移除。

### 简写语法

因为 v-bind 非常常用，我们提供了特定的简写语法：

```html
<div :id="dynamicId"></div>
```

### 同名简写（3.4+）

当然你也可以同名简写

```html
<!-- 与 :id="id" 相同 -->
<div :id></div>

<!-- 这也同样有效 -->
<div v-bind:id></div>
```

### 布尔型 Attribute

布尔型 attribute 依据 true / false 值来决定 attribute 是否应该存在于该元素上。disabled 就是最常见的例子之一。

```html
<button :disabled="isButtonDisabled">Button</button>
```

当 `isButtonDisabled` 为真值或一个空字符串 (即 `<button disabled="">`) 时，元素会包含这个 disabled attribute。而当其为其他假值时 attribute 将被忽略。

### 动态绑定多个值

有时候我们可能需要绑定多个 attribute，比如 `class` 和 `style`。这时候我们可以使用对象语法：

```js
const objectOfAttrs = {
  id: 'container',
  class: 'wrapper',
  style: 'background-color:green',
};
```

通过不带参数的 `v-bind`，你可以将它们绑定到单个元素上：

```html
<div v-bind="objectOfAttrs"></div>
```

## 使用 JavaScript 表达式

至此，我们仅在模板中绑定了一些简单的属性名。但是 Vue 实际上在所有的数据绑定中都支持完整的 JavaScript 表达式：

```js
{{ number + 1 }}

{{ ok ? 'YES' : 'NO' }}

{{ message.split('').reverse().join('') }}

<div :id="`list-${id}`"></div>
```

::: tip 理解
所谓的表达式就是一个能产生值得代码
:::
