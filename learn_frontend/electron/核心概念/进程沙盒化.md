# 进程沙盒化

## 什么是沙盒

沙盒其实就是一个运行环境，它将一个程序运行在一个隔离的环境中，使其不能访问到操作系统的资源，只能访问到沙盒中的资源。沙箱的目的是为了保护用户的系统不受恶意程序的侵害，防止恶意程序对系统造成破坏。

## Chromium 中的沙箱

在 Chromium 中，沙箱机制适用于除主进程之外的大多数进程。这包括渲染器进程，以及音频服务、GPU 服务和网络服务等实用程序进程

## Electron 中的沙箱行为

> 一句话概述：在沙箱中渲染器进程和 Chrome 浏览器一致，只有浏览器相关 API 的使用权限。预加载脚本具有一部分 Node 和 Electron API 的权限。渲染器进程想要使用特权 API，需要通过预加载脚本与主进程进行 IPC 通信。

从 Electron 20 开始，渲染器进程无需额外配置即可启用沙箱。其行为大致与 Chromium 中的沙箱相同。

### 渲染器进程

当 Electron 中的渲染器进程处于沙箱模式时，它们的行为与普通 Chrome 渲染器完全相同。处于沙箱模式的渲染器不会初始化 Node.js 环境。

因此，当沙箱启用时，渲染器进程只能通过进程间通信（IPC）将这些特权任务委托给主进程，才能执行这些任务（例如与文件系统交互、对系统进行更改或启动子进程）。

### 预加载脚本

为了使渲染器进程能够与主进程通信，附加到沙盒渲染器的预加载脚本仍将提供 Electron 和 Node 内置模块的子集：

- `electron`(以下渲染器进程模块：`contextBridge`, `crashReporter`, `ipcRenderer`, `nativeImage`, `webFrame`, `webUtils`)
- `events`
- `timers`
- `url`

也支持导入：

- `node:events`
- `node:timers`
- `node:url`

此外，预加载脚本还会将某些 Node.js 原语填充为全局变量：

- `Buffer`
- `process`
- `clearImmediate`
- `setImmediate`

::: warning 注意
您将无法使用 CommonJS 模块将您的预加载脚本拆分为多个文件。如果您需要拆分预加载代码，请使用诸如 webpack 之类的打包工具
:::

## 配置沙箱

### 禁用单个进程的沙箱

在 Electron 中，你有三种方式禁用单个进程的沙箱。

1. 可以通过构造函数中的 `sandbox: false` 偏好设置 `BrowserWindow` 按进程禁用渲染器沙箱。

```js
app.whenReady().then(() => {
  const win = new BrowserWindow({
    webPreferences: {
      sandbox: false,
    },
  });
  win.loadURL('https://google.com');
});
```

2. 可以通过 BrowserWindow 构造函数中的`nodeIntegration`标志，这个标志代表启用 Node.js 集成时，沙箱功能也会被禁用。

```js
app.whenReady().then(() => {
  const win = new BrowserWindow({
    webPreferences: {
      nodeIntegration: true,
    },
  });
  win.loadURL('https://google.com');
});
```

3. 通过为提供相应的 HTML 布尔属性来实现

```html
<webview nodeIntegration src="page.html"></webview>
```

### 全局启用沙箱

如果您想强制对所有渲染器启用沙箱，也可以使用 `app.enableSandboxAPI`。请注意，此 API 必须在应用的 ready 事件之前调用。

```js
app.enableSandbox();
app.whenReady().then(() => {
  // any sandbox:false calls are overridden since `app.enableSandbox()` was called.
  const win = new BrowserWindow();
  win.loadURL('https://google.com');
});
```

### 禁用 Chromium 的沙箱

您还可以通过`--no-sandboxCLI` 标志完全禁用 Chromium 的沙箱，这将为所有进程（包括实用程序进程）禁用沙箱。
