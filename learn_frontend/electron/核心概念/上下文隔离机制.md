## 上下文隔离机制

### 何为上下文隔离机制？

上下文隔离是一个安全机制，Electron 默认启用，它可确保您的 preload 脚本和 Electron 的内部逻辑与您加载的网站（或者说渲染器进程）运行在不同的上下文当中。其作用在于避免任何特权 API 泄露到您的网页内容代码中，防止网站恶意脚本访问您的操作系统。

### 开启上下文隔离

当开启时，网页将不能访问你在预加载脚本中为全局 `window` 对象添加的任何变量（即便预加载脚本和渲染器共享一个全局作用域），比如如下的代码：

:::code-group

```js [预加载脚本]
// 预加载脚本中为window对象添加一个myAPI属性
window.myAPI = {
  doAThing: () => {},
};
```

```js [渲染器.js]
// 渲染器脚本中访问时为undefined
window.myAPI;
```

:::

### 关闭上下文隔离

在禁用上下文隔离的情况下，您的预加载脚本会与渲染器共享一个公共全局 window 对象。随后，您可向预加载脚本附加任意属性：

::: code-group

```js [预加载脚本]
// preload with contextIsolation disabled
window.myAPI = {
  doAThing: () => {},
};
```

```js [渲染器.js]
// use the exposed API in the renderer
window.myAPI.doAThing();
```

:::
