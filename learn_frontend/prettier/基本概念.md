# 基本概念

## 什么是 Prettier？

`Prettier` 是一款代码格式化工具，它会移除所有原始样式，并确保所有输出的代码都符合一致的风格。也就是在团队开发中保持代码风格的一致性。

## 安装

```js
npm install --save-dev --save-exact prettier
```

## 创建配置文件

然后，创建一个空的配置文件，以便编辑器和其他工具知道您正在使用 Prettier：

```js
node --eval "fs.writeFileSync('.prettierrc','{}\n')"
```

接下来，创建一个`.prettierignore` 文件，以告知 `Prettier CLI` 和编辑器哪些文件需要不做格式化。以下是一个示例：

```js
node --eval "fs.writeFileSync('.prettierignore','# Ignore artifacts:\nbuild\ncoverage\n')"
```

::: tip 使用其它工具的配置文件
如果 Prettier 与运行它的目录位于同一位置且存在 `.gitignore` 文件，则 Prettier 将遵循该 `.gitignore` 中指定的规则。您还可以基于 `.eslintignore`（如果您有的话）来设置您的 `.prettierignore`。
:::

## 使用 Prettier

现在，使用 Prettier 格式化所有文件：

```js
npx prettier . --write
```

::: npx 是什么东西呢？
npx 随附 npm 并允许您运行本地安装的工具。如果您忘记先安装 Prettier，npx 将临时下载最新版本。在使用 Prettier 时，这可不是个好主意，因为我们在每次发布时都会更改代码的格式化方式！因此，在您的 `package.json` 中锁定 Prettier 的特定版本非常重要。而且它还更快。
:::
