# 渲染器

[[toc]]

## 渲染器介绍

渲染器的主要作用就是将虚拟 DOM 渲染到对应平台上，比如浏览器、移动端、服务器端等。从浏览器的角度来看，你就可以理解为渲染器的作用就是将虚拟 DOM 转换为真实 DOM，然后将真实 DOM 插入到页面中。

## 创建渲染器函数 createRenderer

下面是创建渲染器的函数 `createRenderer`，它接收一个渲染器选项，然后返回一个渲染器对象，该对象包含一个 `render` 方法，用于渲染虚拟节点，源码如下：

```js
/**
 * @param renderOptions 渲染器选项，用于指定渲染器的实现
 * @returns {render} 渲染器对象，包含一个render方法，用于渲染虚拟节点
 * @description 创建渲染器，渲染器是一个对象，包含一个render方法，用于渲染虚拟节点
 */
export function createRenderer(renderOptions) {
  // 渲染器选项，包含了对应平台的相关操作API
  const {
    insert: hostInsert,
    remove: hostRemove,
    createElement: hostCreateElement,
    createText: hostCreateText,
    setText: hostSetText,
    setElementText: hostSetElementText,
    parentNode: hostParentNode,
    nextSibling: hostNextSibling,
    patchProp: hostPatchProp,
  } = renderOptions;

  // ...

   * @param vnode 传入的虚拟节点
   * @param container 传入的容器（虚拟节点需要挂在的真实dom），他身上在经历render之后会有一个_vnode属性，用于保存上一次的vnode，同时也用于标识这个dom曾经被挂载过虚拟节点
   */
  const render = (vnode, container) => {
    // ...
  };
  return {
    render,
  };
}
```

## 渲染器选项

在 `vue3` 中渲染器是与平台无关的，从上面的创建渲染器函数就可以看到，我们需要提供一个渲染器选项，这个选项其实就封装了对应平台的相关操作 API。也就是说要想将虚拟 DOM 渲染到对应的平台你只需要提供对应平台的渲染器选项即可。

### 渲染器选项规则

渲染器选项是一个对象其必须包含以下属性：

- `insert(el, parent, anchor)`：在 `parent` 元素下方插入 `el` 元素，`anchor` 元素之前。
- `remove(el)`：从父元素中移除 `el` 元素。
- `createElement(tag, isSvg)`：创建一个元素，`tag` 是元素的标签名，`isSvg` 表示是否是 SVG 元素。
- `createText(text)`：创建一个文本节点。
- `setText(node, text)`：设置 `node` 元素的文本内容。
- `setElementText(el, text)`：设置 `el` 元素的文本内容。
- `parentNode(node)`：获取 `node` 元素的父元素。
- `nextSibling(node)`：获取 `node` 元素的下一个兄弟元素。
- `patchProp(el, key, prevValue, nextValue)`：更新 `el` 元素的 `key` 属性。
- ...还有几个不常用就先不写了

### vue 默认的渲染器选项

`vue`默认提供了浏览器端的渲染实现，即默认针对浏览器端的渲染选项，里面包含真实的 DOM 操作，以此来实现将虚拟 DOM 渲染为真实 DOM。我们来看一看源码：

::: code-group

```js [nodeOps]
export const nodeOps = {
  // 创建元素
  createElement(tag) {
    return document.createElement(tag);
  },
  // 创建文本节点
  createText(text) {
    return document.createTextNode(text);
  },
  // 设置文本
  setText(node, text) {
    node.nodeValue = text;
  },
  // 设置元素文本，会替换所有的子节点为文本节点
  setElementText(node, text) {
    node.textContent = text;
  },
  // 插入节点
  insert(child, parent, anchor) {
    parent.insertBefore(child, anchor || null);
  },
  // 删除节点
  remove(child) {
    const parent = child.parentNode;
    if (parent) {
      // 根节点无法移除
      parent.removeChild(child);
    }
  },
  // 获取父节点
  parentNode(node) {
    return node.parentNode;
  },
  // 获取下一个兄弟节点
  nextSibling(node) {
    return node.nextSibling;
  },
};
```

```js [patchProp]
/**
 * 更新元素的属性
 * @param el 元素
 * @param key 属性名
 * @param prevValue 旧值
 * @param nextValue 新值
 */
export default function patchProp(el, key, prevValue, nextValue) {
  // 更新class
  if (key === 'class') {
    return patchClass(el, nextValue);
    // 更新style
  } else if (key === 'style') {
    return patchStyle(el, prevValue, nextValue);
    // 更新事件
  } else if (/^on/.test(key)) {
    return patchEvent(el, key, nextValue);
  } else {
    // 更新其它属性
    return patchAttr(el, key, nextValue);
  }
}
```

```js [patchClass]
/**
 * 更新元素的class
 * @param el 元素
 * @param value 新值
 */
export default function patchClass(el, value) {
  // 没有值则移除
  if (value == null) {
    el.removeAttribute('class');
  } else {
    // 有值则设置
    el.className = value;
  }
}
```

```js [patchStyle]
/**
 * 更新元素的style
 * @param el 元素
 * @param preValue 旧值
 * @param nextValue 新值
 */
export default function patchStyle(el, preValue, nextValue) {
  // 获取元素的style属性
  let style = el.style;
  // 遍历新样式
  for (let key in nextValue) {
    // 新样式要全部生效
    style[key] = nextValue[key];
  }
  // 旧样式存在新样式不存在要删除
  if (preValue && Object.keys(preValue).length) {
    // 看以前的属性有没有，如果现在没有就删掉
    for (let key in preValue) {
      if (nextValue) {
        if (nextValue[key] === null) {
          style[key] = null;
        }
      }
    }
  }
}
```

```js [patchEvent]
/**
 * 创建事件调用器
 * @param fn 事件回调函数
 * @returns {function} 事件调用器
 * @description 这样做的好处在于替换事件时不用再重新先解绑后绑定事件了而是直接替换函数引用
 */
function createInvoker(fn) {
  const invoker = e => invoker.value(e);
  // 更改invoker中的fn，而不是重新解绑事件再重新绑定新事件
  invoker.value = fn;
  return invoker;
}
/**
 * 更新元素的事件
 * @param el 元素
 * @param name 事件名
 * @param nextValue 新值
 */
export default function patchEvent(el, name, nextValue) {
  // vue_event_invoker 存储事件调用器
  const invokers = el._vei || (el._vei = {});
  // 去除on前缀，然后转为小写
  const eventName = name.slice(2).toLowerCase();
  //  是否存在同名的事件绑定
  const existingInvoker = invokers[name];
  // 若新事件处理函数存在
  if (nextValue) {
    // 有同名事件绑定
    if (existingInvoker) {
      // 同名事件值替换
      existingInvoker.value = nextValue;
    } else {
      // 新增事件绑定
      const invoker = (invokers[name] = createInvoker(nextValue));
      el.addEventListener(eventName, invoker);
    }
  } else if (existingInvoker) {
    // 移除旧事件（没有在新事件中）
    el.removeEventListener(eventName, existingInvoker);
    invokers[name] = undefined;
  }
}
```

```js [patchAttr]
/**
 * 更新属性
 */
export default function patchAttr(el, key, value) {
  // 添加或更新属性
  if (!value) {
    el.removeAttribute(key);
  } else {
    el.setAttribute(key, value);
  }
}
```
