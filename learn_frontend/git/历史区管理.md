# 历史区管理

## 概念

### master 和 HEAD 指针

当只有一个分支时，`master` 和 `HEAD` 指针默认指向最新一次提交。
![ master 和 HEAD 指针](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251211104704632.png)

## 提交到历史区

### git commit

我们使用 `git commit` 这个指令提交暂存区的内容到历史区

```shell
# 把暂存区的内容放到历史区
$ git commit -m "我是第一个版本"
```

::: warning 提交信息
你必须要写提交信息，否则提交不会被记录到历史区。
:::

## 查看历史版本

### git log

我们使用 `git log` 这个指令只能查看本分支的历史提交版本信息:

```shell
# 查看当前历史区版本信息
$ git log
```

但是注意`git log` 只能查看`HEAD`指针之前的版本信息。

```shell
commit 845c963d346f6071b7471a29b7064b9d4f7b788b (HEAD -> master)
Author: bloom_lmh <1357526355@qq.com>
Date:   Thu Dec 11 10:52:25 2025 +0800

    添加css

commit 726156243a94693434bf8eef8bd7854fd5b9c637
Author: bloom_lmh <1357526355@qq.com>
Date:   Thu Dec 11 10:08:52 2025 +0800

    add:A
```

### git reflog

`git reflog` 指令可以查看所有分支的所有操作记录，包括`HEAD`指针的移动情况。

```shell
7261562 (HEAD -> master) HEAD@{0}: reset: moving to HEAD^
845c963 HEAD@{1}: commit: 添加css
7261562 (HEAD -> master) HEAD@{2}: reset: moving to 726156243a94693434bf8eef8bd7854fd5b9c637
7261562 (HEAD -> master) HEAD@{3}: commit (initial): add:A

```

## 回滚版本

### git reset

#### 回退到上一个版本

我们使用 `git reset --hard 版本编号` 进行历史版本号的回退。所谓的回滚版本就是让`HEAD`指针移动指向不同的版本。此时工作区文件会发生变化

```shell
# 回退到上一次提交的版本
$ git reset --hard HEAD^

# 回退到上上次提交的版本
$ git reset --hard HEAD^^
$ git reset --hard HEAD~2

# 回退到指定版本
$ git reset --hard 版本编号
```

#### 回退暂存区

使用 `git reset --soft 版本编号` 指令可以将某个版本回退暂存区。此时工作区文件不会发生变化

::: tip 暂存区的意义
比如我第一次提交了 A 功能代码，此时产生了一次版本。然后我又去开发 B 功能，此时发现 A 功能有 BUG 于是我又修复了 A 功能的代码，此时我又提交了一次版本。这时 A 功能就提交了两次。然而我们希望只提交一次版本，所以我们就可以把第一次提交的 A 功能代码撤回到暂存区，然后再提交一次版本。这样就可以只保留最后一次提交的 A 功能代码。也就是说，暂存区的作用就是用来暂存我们即将提交的修改，直到最后提交到版本库。
:::

### git revert

![git revert](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251211112610423.png)

- `git reset` 是回滚到对应的 `commit-id`，相当于是删除了 `commit-id` 以后的所有的提交，并且不会产生新的 `commit-id` 记录，如果要推送到远程服务器的话，需要强制推送`-f`
- `git revert` 是反做撤销其中的 `commit-id`，然后重新生成一个 `commit-id`。本身不会对其他的提交 `commit-id` 产生影响，如果要推送到远程服务器的话，就是普通的操作 `git push` 就好了

## 删除版本

### git tag

我们使用 `git tag` 这个指令删除版本

```shell
# 删除版本
$ git tag -d 版本号
```
