# 最佳实践

一般来说，日常使用只要记住下图 6 个命令，就可以了。但是熟练使用，恐怕要记住 60 ～ 100 个命令。
![日常工作流程](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251213105534446.png)

下面是我整理的常用 Git 命令清单。几个专用名词的译名如下。

```bash
Workspace：工作区
Index / Stage：暂存区
Repository：仓库区（或本地仓库）
Remote：远程仓库
```

1. 克隆远程仓库到本地
2. 在本地创建开发分支和 BUG 分支进行开发和改 BUG
3. 每天开发完成和改完 BUG 后，先更新主分支后再将这些分支与主分支进行合并
4. 推送主分支到远程，一般来说主分支是大的项目迭代，要设置标签
