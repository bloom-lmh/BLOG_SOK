# 团队协作

## 添加远程链接

`git remote add origin <url>`

## 推送代码

`git push origin master:master`

把本地的 `master` 分支推送到远程的 `master` 分支。

## 团队协作与冲突

在同一版本上不同的分支在同一地方都进行了更改，合并就会发生冲突，因为他不知道要采用哪一版

## 远程分支克隆

`git pull origin 分支名称`

远程和本地分支关联只需要 `pull` 下来后 `checkout` 即可。

通常才说不要再远程添加 bug 分支，改完 bug 合并到开发分支或主分支即可
