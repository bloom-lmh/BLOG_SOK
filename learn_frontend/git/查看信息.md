# 查看信息

## 查看当前状态（工作区 & 暂存区）

> 关注“我现在改了什么？哪些还没提交？”

```bash
# 显示有变更的文件（工作区 + 暂存区状态）
git status

# 显示工作区 vs 暂存区的差异（未暂存的改动）
git diff

# 显示暂存区 vs HEAD 的差异（已暂存但未提交的改动）
git diff --cached          # 或 git diff --staged
```

## 查看提交历史（Commit History）

> 回顾“过去发生了什么？”

```bash
# 显示当前分支的完整提交历史
git log

# 显示每次提交的文件变更摘要
git log --stat

# 显示某次提交的详细变更（含 diff）
git log -p [file]

# 显示最近 N 次提交（简洁格式）
git log -5 --oneline

# 搜索提交内容（如代码中新增/删除了 keyword）
git log -S "keyword"

# 搜索提交信息（commit message）包含关键词
git log --grep "feature"

# 查看某个文件的完整历史（包括重命名）
git log --follow [file]
git whatchanged [file]   # 类似，但更侧重文件变更
```

## 查看具体提交的内容（Inspect a Commit）

> “这个 commit 到底改了什么？”

```bash
# 显示某次提交的元数据 + diff
git show [commit]

# 仅显示该提交修改的文件列表
git show --name-only [commit]

# 查看某次提交中某个文件的具体内容
git show [commit]:path/to/file
```

## 查看分支/引用之间的差异（Comparing References）

> “两个版本之间有什么不同？”

```bash
# 工作区 vs 最近一次提交（HEAD）
git diff HEAD

# 两个提交/分支之间的差异
git diff commit1 commit2        # 或 git diff branchA branchB

# 对称差异（从共同祖先到 branchB 的变更）
git diff branchA...branchB      # 注意三点语法的特殊含义

# 统计今日代码变更（需配合有效时间引用）
git diff --shortstat HEAD@{"$(date '+%Y-%m-%d 00:00:00')"}
```

> 提示：`git diff A B` 是最通用的对比方式；三点语法 `A...B` 用于 PR/合并场景。

## 查看操作记录与引用移动（Reflog）

> “我刚才做了什么操作？HEAD 去过哪里？”

```bash
# 查看 HEAD 的移动历史（包括 reset、checkout、merge 等）
git reflog

# 查看所有分支的操作记录（较少用）
git reflog show --all
```

> `reflog` 是本地记录，不会推送到远程，主要用于恢复误操作（如 `reset --hard` 后找回 commit）。

## 查看作者与协作信息（Blame / Contributors）

> “谁改了这行代码？谁贡献最多？”

```bash
# 显示文件每行最后修改者及提交信息
git blame [file]

# 统计所有提交者及其提交次数（按数量排序）
git shortlog -sn
```

## 总结

| 分类         | 核心问题             | 常用命令                                    |
| ------------ | -------------------- | ------------------------------------------- |
| **当前状态** | 我现在改了什么？     | `status`, `diff`, `diff --cached`           |
| **提交历史** | 过去发生了什么？     | `log`, `log --stat`, `log -S`, `log --grep` |
| **单次提交** | 这个 commit 改了啥？ | `show`, `show --name-only`                  |
| **版本对比** | A 和 B 有什么不同？  | `diff A B`, `diff HEAD`                     |
| **操作回溯** | 我刚才干了啥？       | `reflog`                                    |
| **协作信息** | 谁写的代码？         | `blame`, `shortlog -sn`                     |
