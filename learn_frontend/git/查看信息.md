## 查看历史版本

### git log

我们使用 `git log` 这个指令只能查看本分支的历史提交版本信息:

```shell
# 查看当前历史区版本信息
$ git log
```

但是注意`git log` 只能查看`HEAD`指针之前的版本信息。

```shell
commit 845c963d346f6071b7471a29b7064b9d4f7b788b (HEAD -> master)
Author: bloom_lmh <1357526355@qq.com>
Date:   Thu Dec 11 10:52:25 2025 +0800

    添加css

commit 726156243a94693434bf8eef8bd7854fd5b9c637
Author: bloom_lmh <1357526355@qq.com>
Date:   Thu Dec 11 10:08:52 2025 +0800

    add:A
```

### git reflog

`git reflog` 指令可以查看所有分支的所有操作记录，包括`HEAD`指针的移动情况。

```shell
7261562 (HEAD -> master) HEAD@{0}: reset: moving to HEAD^
845c963 HEAD@{1}: commit: 添加css
7261562 (HEAD -> master) HEAD@{2}: reset: moving to 726156243a94693434bf8eef8bd7854fd5b9c637
7261562 (HEAD -> master) HEAD@{3}: commit (initial): add:A

```
