# 配置管理

## 基本概念

仓库配置是指对仓库提交时或仓库的一些信息参数的设置，通常有两种方式：

1. 以命令的方式
2. 直接修改配置文件

这里只讲以命令的方式配置仓库。

## 配置文件

`Git` 的设置文件为`.gitconfig`，它可以在用户主目录下（全局配置），也可以在项目目录下（项目配置）。

1. 局部的配置文件就在`.git` 下的 `config` 文件中

![局部的配置文件](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251212091952272.png)

2. 全局的配置文件在 `c` 盘下的`.gitconfig` 文件中

![全局的配置文件](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251212092225609.png)

## 全局配置

全局配置是指对所有`Git`操作配置公共的参数，其优先级小于局部配置

命令：`git config --global 参数名 参数值`

比如为所有仓库设置默认提交时的操作者名和邮箱：

```shell
git config --global user.email "you@example.com"
git config --global user.name "Your Name"
```

## 局部配置

局部配置是针对具体的仓库进行参数配置，其优先级大于全局配置
命令：`git config 参数名 参数值`

比如为单个仓库设置提交时的操作者名和邮箱：

```bash
git config user.name bloom
git config user.emain 123123123@qq.com
```
