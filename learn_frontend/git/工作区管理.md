# 工作区管理

## 删除工作区文件

```bash
# 删除工作区文件，并且将这次删除不会放入暂存区
$ git rm [file1] [file2] ...
```

::: tip 文件追踪
如果被手动删除的文件最近一次提交过才会被追踪
:::

## 文件恢复

命令：`git restore` 文件名
我们删除的文件是工作区的文件，而存储区依然存在文件版本备份，所以我们可以进行恢复。但是如果我们将删除操作提交后，则该命令无法进行恢复到最近一次提交文件。

![](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251213092754424.png)
![](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251213092811553.png)
可以看到工作区的文件已经被删除了，但是没有提交暂存区

```bash
$ git status
On branch master
Changes not staged for commit:
  (use "git add/rm <file>..." to update what will be committed)
  (use "git restore <file>..." to discard changes in working directory)
        deleted:    test02.txt

no changes added to commit (use "git add" and/or "git commit -a")
```

根据文件名来进行恢复：`$ git restore test02.txt`

::: warning 注意
该文件必须是已经被追踪的文件，且没有提交删除
:::
