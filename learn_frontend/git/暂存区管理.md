# 暂存区管理

## 添加到暂存区

所谓的添加到暂存区就是将工作区的文件添加到暂存区

### git add

我们要放入暂存区，要使用 `git add` 指令

1. 把单独一个文件放在暂存区

```shell
# 把文件夹下的 index.txt 文本放在暂存区
$ git add index.txt
```

2. 把单独一个文件夹放在暂存区（暂存区不能存放空文件夹）

```shell
# 把文件夹下的 ceshi文件夹 放在暂存区
$ git add ceshi/
```

3. 把所有文件都放在暂存区：下面两种方式都可以

```shell
# 把文件夹下所有的内容都放在暂存区
$ git add --all

# git add --all 有一个简单的写法
$ git add .
```

> git add . 只会把发生变化的文件添加到暂存区，不会把没有变化的文件添加到暂存区。

::: tip 提示
`warning: in the working copy of 'index.txt', LF will be replaced by CRLF the next time Git touches it`
这个命令的意思是`git`帮你将`windows`换行符转换为`linux`的换行符
:::

## 查看暂存区状态

### git status

1. 查看所有文件状态

```shell
$ git status
```

2. 查看具体文件状态

```shell
$ git status index.txt
```

## 撤销暂存区文件

撤销暂存区文件又两种方式：

### git reset

保留自动跟踪：这种方式会保持对文件的跟踪

```shell
# 撤销暂存区文件
$ git reset HEAD index.txt
```

### git rm

2. 不再进行自动跟踪: 这种方式会停止对文件的跟踪

```shell
# 从 Git 中移除文件
git rm --cached index.txt
```
