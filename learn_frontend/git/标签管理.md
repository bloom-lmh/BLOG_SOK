# 标签管理

## 什么是标签？

`Git` 标签（`tag`）在版本控制系统中主要用于标记特定的重要提交，通常用于标识软件发布版本（如 `v1.0.0`、`v2.3.1` 等）。

> 你可以理解为`Git` 标签是一个指向特定 `commit` 的永久指针，用于标记项目历史中的重要节点。它不像分支会移动，一旦创建就固定不变（除非手动删除重建）。

## 具体相关的命令

```bash
# 列出所有tag
$ git tag
# 新建一个tag在当前commit
$ git tag [tag]
# 新建一个tag在指定commit
$ git tag [tag] [commit]
# 删除本地tag
$ git tag -d [tag]
# 删除远程tag
$ git push origin :refs/tags/[tagName]
# 查看tag信息
$ git show [tag]
# 提交指定tag
$ git push [remote] [tag]
# 提交所有tag
$ git push [remote] --tags
# 新建一个分支，指向某个tag
$ git checkout -b [branch] [tag]
```
