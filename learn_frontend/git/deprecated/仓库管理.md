# 仓库管理

## 初始化本地库

如果我们希望一个文件夹拥有版本控制的能力，就需要让该文件夹被 `git` 接管，这个过程叫做**git 初始化**，在该文件下输入命令：`git init`，即可完成初始化。此时该文件夹下会出现一个 `.git` 的隐藏文件夹，里面存放着该文件的版本控制的相关信息。

```shell
# 在当前目录新建一个Git代码库
$ git init
# 新建一个目录，将其初始化为Git代码库
$ git init [project-name]
```

## 克隆远程仓库

将远程仓库克隆到本地

```shell
# 克隆一个仓库
$ git clone [url]
# 克隆到指定目录
$ git clone [url] [directory]
```
