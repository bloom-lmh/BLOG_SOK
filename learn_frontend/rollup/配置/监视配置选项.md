# 监视

[[toc]]

## 触发重建时清屏--clearScreen

触发重建时是否清除屏幕。

## 排除一些被监视的文件 --watch.exclude

防止文件被监视：

```js
// rollup.config.js
export default {
  // ...
  watch: {
    exclude: 'node_modules/**',
  },
};
```

## 包含要监视的文件--watch.include

将文件监视限制为某些文件。请注意，这仅过滤模块图，但不允许添加额外的监视文件：

```js
// rollup.config.js
export default {
  // ...
  watch: {
    include: 'src/**',
  },
};
```
