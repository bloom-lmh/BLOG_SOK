## 基本介绍

### 完整的选项配置

一个完整的 rollup 选项是一个如下的对象:

```js
let inputOptions = {
  input: 'src/main.js',
  plugins: [
    //...
  ],
};
let rollupOptions = {
  // 输入相关选项
  ...inputOptions,
  // 输出相关选项
  output: {
    file: 'dist/bundle.js',
    format: 'cjs',
    name: 'MyLib',
  },
  // 监控相关选项
  watch: {
    clearScreen: true,
    exclude: 'node_modules/**',
    include: 'src/**',
  },
};
```

也就是说有三个部分构成：

1. 输入选项
2. 输出选项
3. 监控选项

### 监控选项

现在我们就来学习下监控选项配置

```js
interface WatcherOptions {
  allowInputInsideOutputPath?: boolean;
  buildDelay?: number;
  chokidar?: ChokidarOptions;
  clearScreen?: boolean;
  exclude?: string | RegExp | (string | RegExp)[];
  include?: string | RegExp | (string | RegExp)[];
  skipWrite?: boolean;
  onInvalidate?: (id: string) => void;
}
```

该选项用于指定观察模式（watch mode）的选项，或防止 Rollup 配置被观察。指定该选项为 false，将仅对 Rollup 使用数组配置时有效。在这种情况下，Rollup 配置将不会根据观察模式中的变更构建或重新构建，而是在 Rollup 运行时定期构建：

## 触发重建时清屏-clearScreen

触发重建时是否清除屏幕。

## 排除一些被监视的文件 --watch.exclude

防止文件被监视：

```js
// rollup.config.js
export default {
  // ...
  watch: {
    exclude: 'node_modules/**',
  },
};
```

## 包含要监视的文件--watch.include

将文件监视限制为某些文件。请注意，这仅过滤模块图，但不允许添加额外的监视文件：

```js
// rollup.config.js
export default {
  // ...
  watch: {
    include: 'src/**',
  },
};
```
