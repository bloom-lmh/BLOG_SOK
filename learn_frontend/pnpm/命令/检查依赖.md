# 检查依赖

[[toc]]

## pnpm audit

### 基本介绍

检查已安装软件包的已知安全问题。如果发现安全问题，请尝试通过 `pnpm update` 更新你的依赖。如果简单的更新无法解决所有问题，请使用 `overrides` 强制使用不易受攻击的版本。例如，如果 `lodash@<2.1.0` 容易受到攻击，请使用此覆盖来强制 `lodash@^2.1.0`：

```bash
overrides:
  "lodash@<2.1.0": "^2.1.0"
```

或者，运行 `pnpm audit --fix`。如果你想容忍某些漏洞，因为它们不影响你的项目，你可以使用 `auditConfig.ignoreCves` 设置。

### 选项

| **选项**                   | **类型/值**                           | **默认值** | **说明**                                                                 |
| -------------------------- | ------------------------------------- | ---------- | ------------------------------------------------------------------------ |
| `--audit-level <severity>` | `low`, `moderate`, `high`, `critical` | `low`      | 仅显示指定严重级别及以上的漏洞报告                                       |
| `--fix`                    | 无                                    | -          | 自动修改 `package.json`，强制使用无漏洞的依赖版本                        |
| `--json`                   | 无                                    | -          | 以 JSON 格式输出审计报告                                                 |
| `--dev`, `-D`              | 无                                    | -          | 仅检查开发依赖（`devDependencies`）                                      |
| `--prod`, `-P`             | 无                                    | -          | 仅检查生产依赖（`dependencies`）                                         |
| `--no-optional`            | 无                                    | -          | 忽略可选依赖（`optionalDependencies`）                                   |
| `--ignore-registry-errors` | 无                                    | -          | 如果注册表返回非 200 状态码（如网络错误），仍以状态码 0 退出（视为成功） |
| `--ignore-unfixable`       | 无                                    | -          | 忽略所有无法修复的漏洞（v10.11.0 新增）                                  |
| `--ignore <vulnerability>` | 漏洞 ID（如 `CVE-2023-1234`）         | -          | 忽略指定的漏洞（v10.11.0 新增）                                          |

## pnpm list

### 基本介绍

别名：`ls`此命令将以树形结构输出已安装的软件包的**所有版本及其依赖**。
位置参数是 `name-pattern@version-range` 标识符，它将结果限制为仅指定的包。例如，`pnpm list "babel-*" "eslint-*" semver@5`。

### 选项

| 选项                          | 别名 | 说明                                                                                                       |
| ----------------------------- | ---- | ---------------------------------------------------------------------------------------------------------- |
| `--recursive`                 | `-r` | 在工作区中执行时，对子目录中的每个包或每个工作区包执行命令                                                 |
| `--json`                      |      | `JSON` 格式的日志输出                                                                                      |
| `--long`                      |      | 显示扩展信息                                                                                               |
| `--parseable`                 |      | 以可解析的格式输出包目录而不是树视图                                                                       |
| `--global`                    | `-g` | 列出全局安装目录中的包，而不是当前项目中的包                                                               |
| `--depth <number>`            |      | 依赖树的最大显示深度。`--depth 0` 仅列出直接依赖，`--depth -1` 仅列出项目，`--depth Infinity` 列出所有依赖 |
| `--prod`                      | `-P` | 仅显示 `dependencies` 和 `optionalDependencies` 中的包的依赖图                                             |
| `--dev`                       | `-D` | 仅显示 `devDependencies` 中包的依赖图                                                                      |
| `--no-optional`               |      | 不显示 `optionalDependencies` 的包                                                                         |
| `--only-projects`             |      | 仅显示也是工作区中的项目的依赖                                                                             |
| `--exclude-peers`             |      | 从结果中排除对等依赖（但不会忽略对等依赖的依赖）                                                           |
| `--filter <package_selector>` |      | 了解有关过滤的更多信息                                                                                     |
| `--find-by <finder_name>`     |      | 使用在 `.pnpmfile.cjs` 中定义的查找器函数来通过名称以外的属性匹配依赖（`v10.16.0` 新增）                   |

## pnpm outdated

### 基本介绍

检查是否有过时的软件包。通过提供参数（支持模式），可以将检查限制为已安装软件包的子集。

```bash
# 检查所有的包
pnpm outdated
pnpm outdated "*gulp-*" @babel/core
```

### 选项

| **选项**                      | **别名** | **说明**                                                     |
| ----------------------------- | -------- | ------------------------------------------------------------ |
| `--recursive`                 | `-r`     | 检查子目录或工作区中的每个包的过时依赖                       |
| `--filter <package_selector>` |          | 根据指定的包选择器过滤结果                                   |
| `--global`                    | `-g`     | 列出全局安装的过时包                                         |
| `--long`                      |          | 打印详细的过时信息                                           |
| `--format <format>`           |          | 设置输出格式（`table`、`list`、`json`），默认为 `table`      |
| `--compatible`                |          | 仅显示符合 `package.json` 中版本约束的更新                   |
| `--dev`                       | `-D`     | 仅检查 `devDependencies` 中的过时依赖                        |
| `--prod`                      | `-P`     | 仅检查 `dependencies` 和 `optionalDependencies` 中的过时依赖 |
| `--no-optional`               |          | 不检查 `optionalDependencies` 中的过时依赖                   |
| `--sort-by`                   |          | 指定排序方式（目前仅支持 `name`）                            |

## pnpm why

显示依赖于指定包的所有包。如果依赖树的结果（结束叶）超过 `10` 个，则输出将被截断为 `10` 个结束叶。这使得输出更具可读性并避免内存问题。

| **选项**                      | **别名** | **说明**                                                             |
| ----------------------------- | -------- | -------------------------------------------------------------------- |
| `--recursive`                 | `-r`     | 在工作区中递归显示每个子包或工作区包的依赖树                         |
| `--json`                      |          | 以 JSON 格式输出依赖树信息                                           |
| `--long`                      |          | 显示详细的依赖树信息                                                 |
| `--parseable`                 |          | 以可解析的格式输出（非树状视图）                                     |
| `--global`                    | `-g`     | 显示全局安装的包依赖树（而非当前项目）                               |
| `--prod`                      | `-P`     | 仅显示 `dependencies` 中的依赖树                                     |
| `--dev`                       | `-D`     | 仅显示 `devDependencies` 中的依赖树                                  |
| `--depth <number>`            |          | 限制依赖树的显示深度（如 `--depth 1` 仅显示直接依赖）                |
| `--only-projects`             |          | 仅显示工作区中项目的依赖（排除非项目依赖）                           |
| `--exclude-peers`             |          | 排除对等依赖（但保留对等依赖的依赖）                                 |
| `--filter <package_selector>` |          | 根据包选择器过滤结果                                                 |
| `--find-by <finder_name>`     |          | 使用 `.pnpmfile.cjs` 中定义的查找器按非名称属性匹配依赖（v10.16.0+） |
