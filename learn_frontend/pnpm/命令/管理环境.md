# 管理环境

## 基本介绍

`pnpm env <cmd>`这个命令用来管理环境变量。类似于`nrm`

### 安装并使用指定版本的 node

安装并使用指定版本的 `Node.js`，比如安装 `Node.js` 的 `LTS` 版本：

```bash
pnpm env use --global lts
```

安装 `Node.js v16`：

```bash
pnpm env use --global 16
```

安装 `Node.js` 的预发布版本：

```bash
pnpm env use --global nightly
pnpm env use --global rc
pnpm env use --global 16.0.0-rc.0
pnpm env use --global rc/14
```

### 仅安装指定版本的 node

安装指定版本的 `Node.js`，但不将其激活为当前版本。

```bash
pnpm env add --global lts 18 20.0.1
```

### 删除指定的 Node.js 版本

```bash
pnpm env remove --global 14.0.0
pnpm env remove --global 14.0.0 16.2.3
```

### 列出已安装的 Node.js 版本

列出本地或远程可用的 `Node.js` 版本
打印本地安装的版本(仅仅是本地已经下载的)：

```bash
pnpm env list
```

打印远程可用的 `Node.js` 版本(它存放在 `pnpm` 官方维护的服务器上，就像一个巨大的、应有尽有的“`Node.js` 版本库”)：

```bash
pnpm env list --remote
```

打印远程可用的 `Node.js v16` 版本：

```bash
pnpm env list --remote 16
```

## 选项

`--global, -g`：更改将在整个系统范围内生效。
