# 过滤

## 基本介绍

过滤允许你将命令限制为包的特定子集。`pnpm` 支持丰富的选择器语法，用于按名称或关系选择包。选择器可以通过 `--filter`（或 `-F`）标志指定：

## 匹配

### 选择包--filter <package_name>

要选择精确的包，只需指定其名称 (`@scope/pkg`) 或使用模式来选择一组包 (`@scope/*`)。示例：

```ts
pnpm --filter "@babel/core" test
pnpm --filter "@babel/*" test
pnpm --filter "*core" test
```

指定包的范围是可选的，因此如果找不到 `core`，`--filter=core` 将选择 `@babel/core`。但是，如果工作区有多个同名的包（例如 `@babel/core` 和 @`types/core`），则不带范围的过滤将不会选择任何内容。

### 选择包及其依赖--filter <package_name>...

要选择包及它所依赖的所有包（直接和非直接），请在包名称后添加省略号：`<package_name>...`。例如，下一个命令将运行 `foo` 及其所有依赖的测试：

```ts
pnpm --filter foo... test
```

你可以使用模式来选择一组根包：

```ts
pnpm --filter "@babel/preset-*..." test
```

::: tip 理解
简单来说，这个命令会执行两个部分的测试：

1. foo 包本身的测试。
2. foo 包为了能正常工作所需要依赖的其他所有包的测试。

:::

### 仅选择包的依赖项--filter <package_name>^...

要仅选择包的依赖（直接和非直接），请在名称后添加上述省略号，前面加上 `V` 形符号。例如，下一个命令将为 `foo` 的所有依赖运行测试：

```ts
pnpm --filter "foo^..." test
```

### 选择这个包及其依赖于这个包的包--filter ...<package_name>

要选择依赖于这个包的所有包（包含本包）（直接和非直接），请在包名称前添加省略号前缀：`...<package_name>`。例如，这将运行 foo 以及依赖它的所有包的测试：

### 仅选择依赖于这个包的包--filter "...^<package_name>"

要仅选择依赖于这个包的包（直接和非直接），请在包名称前添加省略号和 V 形符号。例如，这将为所有依赖于 foo 的包运行测试：

### 没有包时失败--fail-if-no-match

如果你希望 CLI 在没有包与过滤器匹配的情况下失败，请使用此标志。

## 排除

当任何过滤器选择器具有前导 "`!`" 时，它们都可以用作排除运算符。在 `zsh`（可能还有其他 `shell`）中，"`!`" 应该被转义：\!。例如，这将在除 `foo` 之外的所有项目中运行命令：

```ts
pnpm --filter=!foo <cmd>
```

这将在不在 `lib` 目录下的所有项目中运行命令：

```ts
pnpm --filter=!./lib <cmd>
```

## 多重性

过滤包时，将采用至少与一个选择器匹配的每个包。你可以根据需要使用任意多个过滤器：

```ts
pnpm --filter ...foo --filter bar --filter baz... test
```

### 省略`devDependencies` --filter-prod <filtering_pattern>

从工作区选择依赖目时，其行为与 `--filter` 相同，但省略 `devDependencies`。
