# 配置

[[toc]]

## 配置方式

`pnpm` 使用 `npm` 的配置 格式。因此，你应该以与 `npm` 相同的方式设置配置。例如

```bash
pnpm config set store-dir /path/to/.pnpm-store
```

如果未配置存储，则 pnpm 将自动在同一驱动器上创建一个存储。如果你需要 `pnpm` 跨多个硬盘驱动器或文件系统工作，请阅读[常见问题](https://pnpm.nodejs.cn/faq/#does-pnpm-work-across-multiple-drives-or-filesystems)。

## 私有注册表(仓库)

此外，`pnpm` 使用与 `npm` 进行安装相同的配置。如果你有一个私有注册表并且 `npm` 配置为使用它，则 `pnpm` 也应该能够授权请求，而无需额外配置。

> 私有注册表就是一个公司或团队自己搭建的“内部 `npm` 仓库”​，用来存放私有的、不公开的 `JavaScript` 包 ​（比如公司内部开发的工具库、业务组件等）。
> `​npm` 官方注册表 ​（https://registry.npmjs.org） → 像 ​​“公共图书馆”​，所有人都能下载里面的书（开源包）。

## 标志参数（命令行选项）

除了这些选项之外，`pnpm` 还允许你使用所有标志参数（命令行选项）（例如 `--filter` 或 `--workspace-concurrency`）作为选项：

```bash
# 解释：只给名为 `my-app` 的包安装 lodash
pnpm --filter=my-app add lodash
# 解释：一次只安装一个包（非常慢，但可能更稳定）
# pnpm默认并发安装
pnpm install --workspace-concurrency=1
```
