# 简介与安装

## 环境准备

### 安装 nodejs

[官网](https://nodejs.org/en)

### 配置环境变量

`Path` 是操作系统的一个环境变量，可以设置一些文件夹的路径，输入命令后会先在当前目录下找可执行文件，在当前工作目录下找不到可执行文件时，就会在环境变量 `Path` 的目录中挨个的查找，如果找到则执行，如果没有找到就会报错

## node 版本管理工具 nvm

### nvm 介绍

`nvm`全称`Node Version Manager`顾名思义它是用来管理`Node`版本的工具，方便切换不同版本的`node`

### 下载与安装

首先先下载 `nvm`,[下载地址](https://github.com/coreybutler/nvm-windows/releases)，选择 `nvm-setup.exe` 下载即可

### 常用命令

| 命令                    | 说明                            |
| ----------------------- | ------------------------------- |
| `nvm list available`    | 显示所有可以下载的 Node.js 版本 |
| `nvm list`              | 显示已安装的版本                |
| `nvm install 18.12.1`   | 安装 18.12.1 版本的 Node.js     |
| `nvm install latest`    | 安装最新版的 Node.js            |
| `nvm uninstall 18.12.1` | 删除某个版本的 Node.js          |
| `nvm use 18.12.1`       | 切换 18.12.1 的 Node.js         |

## Nodejs 简介

### 什么是 node.js

`Node.js`是一个`javascript`运行环境。它让`javascript`可以开发后端程序，实现几乎其他后端语言实现的所有功能，可以与`PHP、Java、Python、.NET、Ruby`等后端语言平起平坐。
`Nodejs`是基于`V8`引擎，`V8`是`Google`发布的开源`JavaScript`引擎，本身就是用于`Chrome`浏览器的`js`解释部分，但是`Ryan Dahl` 把这个`V8`搬到了服务器上，用于做服务器的软件。也就是说`node.js`本质上就是一个基于`V8`引擎的，解析`js`代码的运行在后端的服务器软件，下面是浏览器和`node`的架构图

![什么是 node.js](https://image-bucket-1307756649.cos.ap-chengdu.myqcloud.com/image/20251215193414642.png)

### node.js 的特点

`Nodejs`语法完全是`js`语法，只要你懂`js`基础就可以学会`Nodejs`后端开发，唯一的区别就是浏览器提供的`API`是面向浏览器的而`node`提供的`API`是面向系统的，两者不完全一样，不可以相互调用。比如`node`环境下就不可以调用浏览器的`DOM`和`BOM`等操作浏览器的相关`API`。`Node`所提供的 API 多数是系统级别的 API，如：文件的读写 (File System)、进程的管理 (Process)、网络通信 (HTTP/HTTPS)等，它没有浏览器安全级别的限制
