# claude code核心概念

## 会话管理

### 默认行为

1. 会话保存：每次工作时会将会话保存在本地，记录每条消息、工具使用和结果，这使得回退、恢复和分叉会话成为可能。并且Claude在进行代码更改之前，它还会对受影响的文件进行快照，以便您在需要时可以恢复。
2. 会话独立：每个新会话都以新的上下文窗口开始，没有来自以前会话的对话历史。
3. 自动内存：同一个项目之间会话是隔离的，你可以使用自动内存跨会话保持学习，即在 `CLAUDE.md` 中添加您自己的持久说明。
4. 针对目录：Claude Code的对话是相对于你的目录文件的而不是相对于你的的分支的。也就是说即便你切换了分支，Claude对你的历史会话保持不变。

### 会话分支

会话分支，本质上是建立在某个上下文快照上的新会话，而不是建立在某个代码版本快照上的分支。他与git没有关系，使用git分支仅仅是为了避免代码冲突

- 同一任务连续追问：同一个 session 里 continue/resume
- 同一分析想试两个方案：fork session
- 两个方案都要落代码：新 Git branch
- 两个方案还要并行同时跑：新 branch + 新 worktree + 各开一个 Claude 会话
