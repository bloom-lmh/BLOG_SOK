# Claude code

## 概述

### 简介

`Claude code`就是一个智能体，以前需要人去问ai，然后ai指示人去改代码，搜索网页等，然后做完一步后人再去问ai，再改进，循环进行，本质上还是以人为主体。而`claude code`就是你的代理，你只需要给他下达任务，他就会帮你问ai，然后根据ai帮你去执行各类操作，你只需要提需求得到最终结果就行。

### 几种使用方式

有几种使用`Claude code`的方式

1. 命令行终端：通过命令来驱动`Claude code`
2. 编辑器集成：vscode、cursor、jetBrains插件等
3. 桌面客户端：一个独立应用，用于在 IDE 或终端之外运行 Claude Code
4. 网页端:主要用于处理你本地没有的仓库，或并行运行多个任务

::: tip 第三方提供商
终端 CLI 和 VS Code 也支持第三方提供商提供api
:::

### 能干什么

1. 自动化研发琐事：自动编写单元测试、修复 Lint 错误、更新依赖及解决合并冲突。
2. 全流程功能修复：跨文件追踪上下文，自主规划方案、编写代码并运行测试验证。
3. Git 工作流自动化：自动管理分支、暂存更改，并生成语义化 Commit 与 Pull Request。
4. MCP 跨工具互联：通过标准协议读写 Jira、Slack、Google Drive 等外部数据源。
5. 项目规范与自动记忆：通过 `CLAUDE.md` 注入工程标准，并自动记录构建与调试经验。
6. 多智能体并行协作：支持主从架构（Master-Worker），多代理分身协同处理复杂任务。
7. 管道化脚本集成：兼容 Unix 哲学，支持通过 CLI 管道将日志或任务流接入自动化脚本。
8. 定时任务：支持云端/本地排班，在离线状态下自动执行夜间审计或 PR 审查。
9. 跨端环境无缝流转：支持在手机、浏览器与终端间实时同步会话，随时随地接管任务。

## 快速开始

下面以命令行终端为例，介绍如何使用`Claude code`，本质上可以理解为为命令行装了个有大脑的代理

### 安装 Claude Code

这里选择通过`windows powerShell`来进行安装

```bash
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

::: tip 注意

1. Windows 需要安装 Git for Windows。如果尚未安装，请先进行安装。
2. 原生安装程序会在后台自动更新，确保你始终使用最新版本

:::

### 登录您的账户

Claude Code 需要账户才能使用。当您使用 claude 命令启动交互式会话时，您需要登录：

```bash
# 首次使用时系统会提示您登录
claude
# 按照提示使用您的账户登录
/login
```

您可以使用以下任何账户类型登录：

1. 使用官方订阅：Claude Pro、Max、Teams 或 Enterprise（推荐）
2. 使用 API 访问：具有预付费额度的 API 访问
3. 企业云提供商：相当于各个ip代理商

### 启动您的第一个会话

在任何项目目录中打开您的终端并启动 Claude Code：

```bash
cd /path/to/your/project
claude
```

您将看到 Claude Code 欢迎屏幕，其中包含您的会话信息、最近的对话和最新更新。输入 `/help` 查看可用命令，或输入 `/resume` 继续之前的对话。

### 提出您的第一个问题

想问什么问什么，注意你的token就行

### 在 Claude Code 中使用 Git

Claude Code 使 Git 操作变得对话式：

```bash
# 以前需要输入命令git checkout -b feature/quickstart
# 现在只要告诉它
创建一个名为 feature/quickstart 的新分支

# 你还可以做更多
显示我最后的 5 次提交
```

### 修复错误或添加功能

Claude 擅长调试和功能实现。用自然语言描述您想要的内容：向用户注册表单添加输入验证

## 常用命令

| 命令                | 功能                       | 示例                                |
| :------------------ | :------------------------- | :---------------------------------- |
| `claude`            | 启动交互模式               | `claude`                            |
| `claude "task"`     | 运行一次性任务             | `claude "fix the build error"`      |
| `claude -p "query"` | 运行一次性查询，然后退出   | `claude -p "explain this function"` |
| `claude -c`         | 在当前目录中继续最近的对话 | `claude -c`                         |
| `claude -r`         | 恢复之前的对话             | `claude -r`                         |
| `claude commit`     | 创建 Git 提交              | `claude commit`                     |
| `/clear`            | 清除对话历史               | `/clear`                            |
| `/help`             | 显示可用命令               | `/help`                             |
| `exit` 或 `Ctrl+C`  | 退出 Claude Code           | `exit`                              |

## 最佳实践

1. 请求尽量具体
2. 使用分步说明
3. 让 Claude 先理解代码和要做的工作
4. 使用快捷方式节省时间：比如`?`查看所有可有的快捷键，使用 `Tab` 进行命令补全等
