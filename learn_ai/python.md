## 使用解释器

### 唤出解释器

1. Python解释器通常安装在Unix系统的`/usr/local/bin`目录，通过python启动。通过`Control-D`或`quit()`退出

2. Windows系统可用python或py命令（py.exe启动器）启动。通过`Control-Z`或`quit()`退出

### 传入参数

Python 解释器会把命令行输入的所有参数，整理成一个字符串列表，存在 `sys` 模块的 `argv` 变量里；

比如：输入 `python3.14 -m os`：`sys.argv [0]` 是模块全名（含目录，比如 'os'），若加额外选项（`python3.14 -m os --help`），`--help` 不被解释器处理，留给 `os` 模块自己解析。

### 交互模式

支持交互式编辑、脚本运行、`-c`执行命令、`-m`运行模块及`-i`交互模式运行脚本等方式

在终端（tty）输入并执行指令时，解释器在 交互模式（interactive mode） 中运行。在这种模式中，会显示

1. 主提示符，提示输入下一条指令，主提示符通常用三个大于号（`>>>`）表示；2. 输入连续行时，显示 次要提示符，默认是三个点（`...`）

## 解释器的运行环境

### 字符编码

Python 源码文件的编码是 UTF-8
如果不使用默认编码，则要声明文件的编码，文件的 第一 行要写成特殊注释。句法如下：

```bash
# -*- coding: encoding -*-
```

第一行 的规则也有一种例外情况，源码以 UNIX "shebang" 行 开头。此时，编码声明要写在文件的第二行。例如：

```bash
#!/usr/bin/env python3
# -*- coding: cp1252 -*-
```

## Python 速览

### Python 用作计算器

整数（如，2、4、20）的类型是 `int`，小数（如，5.0、1.6）的类型是 `float`

1. `/`：除法运算 总是返回浮点数
2. `//`：得到一个整数`floor division`结果
3. `%`：要计算余数你可以使用
4. `**`：乘方运算
5. `=`：赋值运算符
6. `_`: 交互模式下，上次输出的表达式会赋给变量 `_`

### 文本

如果不希望前置 `\` 的字符转义成特殊字符，可以使用 原始字符串，在引号前添加 `r` 即可：

```py
print('C:\this\name')  # 这里 \t 表示制表符，\n 表示换行符
print(r'C:\this\name')  # 请注意引号前的 r
```
