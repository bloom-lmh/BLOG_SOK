# [自动研究auto reasearch](https://github.com/karpathy/autoresearch)

> 一句话概述：autoresearch 是一个让 AI agent 自动修改训练代码、运行短时实验、根据指标保留有效改动的研究框架，本质上是在用低成本、高频率、自动化的方式搜索“固定预算下更优的模型结构和训练配置

## 什么是auto reasearch

`auto reasearch`其实是一个解决方案，就是用ai自动代理人去做实验，让科研人员摆脱繁琐重复的科研过程。比如平常做模型研究时，人会反复做这几件事：

1. 改训练代码
2. 跑一次训练
3. 看指标有没有变好
4. 保留或放弃这次改动
5. 再继续下一轮

`autoresearch` 想把这整个循环交给 AI agent 自动做。它的目标是：让 AI 一晚上自动试很多版训练方案，第二天你起来看实验日志和最优结果。

## 核心文件

最重要的三个角色

1. `prepare.py`：作用是准备数据、训练 `tokenizer`、做数据加载和评估工具。这个文件基本不动，相当于底层基础设施。
2. `train.py`：是实验主战场，agent 会不断修改这里的模型结构、超参数、优化器和训练策略。
3. `program.md` 是人写给 agent 的研究说明书，定义它应该怎么做实验、怎么判断改动是否有效。

## 工作流程

从工程视角看，这相当于把调参这件事抽象成了一个自动化闭环：

1. agent 读取 `program.md`
2. 修改 `train.py`
3. 启动一次训练
4. 在固定 5 分钟内拿到结果
5. 用 val_bpb 判断这次改动有没有提升
6. 提升就保留，不提升就丢弃
7. 进入下一轮

### 固定时间预算

这是全文里一个很关键的设计。作者不是想比较谁最后训练得更久，而是想比较：在同样 5 分钟内，哪种改法最划算。

这样做有两个好处：

1. 不管 AI 改了模型结构还是 `batch size`，大家都在同样时间预算下比，比较公平
2. 它会自然找到在你这台机器上，5 分钟内最优的方案，所以它优化的不是理论最强模型，而是：在固定短时间预算内，效果最好的训练配置。

### 什么是val_bpb

全称是 `validation bits per byte`。你可以先不用深究数学定义，只记住一句：它越低越好
