## 项目一：课程商城 `course-mall`（Java 微服务电商后端）

> 定位：一个从单体到微服务的完整电商后端，覆盖注册登录、课程、订单、支付、秒杀、搜索、部署全链路。不是 demo——有完整业务、有并发、有分布式问题。

### 业务模块

| 模块 | 核心功能 |
|---|---|
| 用户 | 注册、登录、JWT 鉴权、验证码、个人信息 |
| 课程 | 课程 CRUD、分类/标签、条件分页搜索、上下架 |
| 订单 | 下单、订单状态机、库存扣减、支付回调、退款 |
| 库存 | 扣减/回补、防超卖、乐观锁 |
| 秒杀 | 秒杀活动、限购、Redis 原子扣减、削峰 |
| 支付 | 第三方沙箱对接、回调幂等 |
| 搜索 | ES 全文检索、高亮、聚合、深分页 |

## 项目二：智能问答 Agent `qa-agent`（Python AI Agent）

> 定位：一个能落地到业务的 RAG + Agent 问答系统，支持文档问答、工具调用、多轮对话、流式输出、多 Agent 编排。不是「调一下 API 就完」——有完整工程。

### 核心能力

| 能力 | 说明 |
|---|---|
| 多轮对话 | 短期/长期记忆、上下文窗口管理 |
| 工具调用 | Function Calling 查数据、查天气、搜索 |
| 文档问答 | RAG：切分、向量化、混合检索、重排、引用溯源 |
| Agent 编排 | ReAct、多步推理、多 Agent 协作 |
| 流式输出 | SSE 流式、打字机效果、停止生成 |
| 工程化 | 评估、成本优化、Docker 部署、MCP 集成 |
