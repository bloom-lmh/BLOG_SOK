# 森海塞尔 momentum4

这里分享下森海塞尔的`momentum4`的调音

## 几个输出方式

### 3.5mm 的线

原理：当采用 3.5mm 的线输出时，是采用的`windows`内部的声卡来进行输出，也就是会经历下面的步骤：`电脑声卡→数字信号→电脑内部DAC→模拟信号→3.5mm线→耳机`

缺点：

1. 依赖电脑声卡的内置 `DAC` 性能
2. 无法调用耳机内部的 `DSP` 处理单元

### USB 数字连接模式

原理：当采用 USB 输出时，会采用耳机内部的 `DAC` 来进行解码：`电脑→USB线（数字信号）→耳机内置DAC→模拟信号→扬声器`
核心优势:

1. 跳过电脑声卡，直接使用耳机高性能`DAC`（如 `Momentum 4` 的森海塞尔定制芯片）
2. 支持`24bit/96kHz`高解析音频（远超 `3.5mm` 的 `16bit/44.1kHz`）

::: tip 什么是 DAC
全称：`Digital-to-Analog Converter`
作用：把电脑/手机里的“数字音频”（一堆 0 和 1）转换成模拟电信号，耳机/音箱才能发出声音。

:::

### 蓝牙模式

原理：当采用蓝牙输出时，会采用耳机内部的 `DSP` 处理单元来进行解码：`电脑→蓝牙模块（数字信号）→耳机内置DSP→模拟信号→扬声器`

缺点：电脑蓝牙驱动默认采用`AAC`或`SBC`编码（压缩率高、码率低），导致音频数据大幅损失。

::: tip 什么是 DSP
全称：`Digital Signal Processing Unit`
作用：对数字音频信号进行实时处理，比如降噪、EQ 调音、空间音效等。
类比：像一个“AI 修音师”，自动给人声打光、给低音加混响。
:::

## 专业术语理解

### 什么是模拟信号

数字信号是没有形状的，而模拟信号则是有形状的，可以用各种各样的波形来表示。

### EQ 效果的核心原理

`EQ（Equalizer）`效果，也就是均衡器效果，是音频处理中最核心、最基础的工具之一。它的本质就像一个调色盘，让你可以分别调节声音中高、中、低等不同频段的音量大小，从而改变整体音色。无论是想让歌声更清晰、给音乐增强节奏感，还是消除令人烦躁的噪音，都离不开`EQ`的精细调整

### aptX 编码

蓝牙传输带宽有限，不能直接传原始音频，必须压缩，不同编码方式 = 不同的“压缩算法”

| 编码类型      | 码率（约）   | 音质                        | 支持设备         |
| :------------ | :----------- | :-------------------------- | :--------------- |
| SBC           | 328 kbps     | 一般（基础蓝牙）            | 所有蓝牙设备     |
| AAC           | 250 kbps     | 中等（苹果常用）            | iPhone、Mac      |
| aptX          | 352 kbps     | 较好（延迟低）              | 安卓高端机       |
| aptX Adaptive | 279–420 kbps | 动态调整，接近 CD           | 新款安卓/Windows |
| aptX Lossless | ~1 Mbps      | 无损（需 Snapdragon Sound） | 极少数设备       |

### 码率（Bitrate）

单位：`kbps`（千比特每秒）
意思：每秒传输多少音频数据。
码率越高 → 压缩越少 → 音质越好（但需要更强的蓝牙芯片支持）

码率衡量的是蓝牙传输的能力

### 透明聆听

就是允许耳机接受来自外部的音频信号，也就是减少降噪等效果。

### Windows Sonic

是指微软 `Windows` 操作系统中内置的一种空间音频技术，名为 `Windows Sonic`，专门用于提升通过耳机（尤其是立体声耳机）聆听音频时的沉浸感和空间感

## 维护建议

1. 耳机长期使用`usb`需要每月放电到`40%`
2. 使用低瓦数的充电器，通常来说是`5v，1A，1000mAh`，充电时间建议在`1`小时左右。
